# 07-去AI味与声音校准

以下为流程化整理的复用提示词，不是历史聊天原文。

## 提示词 1

```text
请读取 humanizer skill，对 [初稿路径] 做去 AI 味编辑。
以我认可的旧文 [样本路径1、2] 校准声音，先概括样本的语言特点。
先定位套话、空泛判断、机械连接、重复总结、对称句和过度加粗，再针对问题改写。
保留我的核心判断、技术术语、数字、引文、事实边界和必要操作步骤。
不要添加未发生的经历、感受或对白，不把不确定结论改成肯定结论。
完成第一遍后，重新检查还有哪些句子明显模板化，进行第二遍局部修改。
输出润色稿和简短修改说明；无法判断的事实交给核对清单。
```

## 提示词 2

```text
按 wechat-chinese-edit 方法，只修改标出的中文段落。
删除不增加信息的连接词和空话，调整句长、重复词与段落节奏。
保留事实、术语、引用和语气强度，避免全文重新生成。
```
