# 07-去AI味与声音校准

以下为流程化整理的复用提示词，不是历史聊天原文。

## 提示词 1

```text
请读取 skills/wechat-07-humanize/SKILL.md 及其可读性参考，编辑 [初稿路径]。
先依据素材优化故事性开头，再从已有判断提炼少量金句，随后按需用 humanizer 润色。
以我认可的旧文 [样本路径1、2] 校准声音，先概括样本的语言特点。
先定位套话、空泛判断、机械连接、重复总结、对称句和过度加粗，再针对问题改写。
保留我的核心判断、技术术语、数字、引文、事实边界和必要操作步骤。
不要添加未发生的经历、感受或对白，不把不确定结论改成肯定结论。
完成第一遍后，重新检查还有哪些句子明显模板化，进行第二遍局部修改。
输出润色稿和简短修改说明：开头素材依据、保留的金句及位置、未解决的材料缺口。
没有合适的故事或短句时说明理由；无法判断的事实交给核对清单。
```

## 提示词 2

```text
按 wechat-chinese-edit 方法，只修改标出的中文段落。
删除不增加信息的连接词和空话，调整句长、重复词与段落节奏。
保留事实、术语、引用和语气强度，避免全文重新生成。
```

## 提示词 3：只优化故事开头和观点短句

```text
读取步骤 07 的 references/readability.md。
只优化当前稿件的开头与关键观点短句，保留其他结构和内容。
开头从有依据的作者经历、可回查案例或明确标注的假设场景中选材。
金句从现有观点提炼，放在有论据支撑的位置，保留必要条件。
不添加无记录的情节、感受、对白、数字或名人引语。
输出改稿及每处修改对应的原意或素材；没有合适候选时保留原文。
```
