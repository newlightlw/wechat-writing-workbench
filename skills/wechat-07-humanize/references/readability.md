# 故事性开头与观点金句

用于公众号初稿的可读性润色。以作者观点、判断和证据为底稿，具体操作优先于词藻加工。

## 一、开头先带读者进入一件具体的事

先找素材，再安排叙述。可用来源按当前稿件选择：

1. 有记录的作者经历：任务、具体动作、遇到的问题、作出的选择及依据。
2. 有来源的他人案例：说明出处与必要背景，转述不冒充亲历。
3. 明确标注的教学构造：用“假设”“设想一个场景”等方式引入，人物与结果只属于这个示例。
4. 缺少事件素材：用读者眼前的具体任务或问题开场，保留材料缺口。

从素材中挑选最能连接主线的一刻。围绕“当时要做什么—发生了什么—为什么需要作出判断—读者会遇到什么问题”组织；顺序可调整，素材没有转折时保持平实。
开头通常用几个短段落就进入主题，再说明本文能提供什么。技术问题紧急、事实简报等场景可直接给结论，不强行故事化。

事实边界：只使用有依据的动作、数字、结果、对白、时间与感受。作者的第一人称判断保留本意。通过选材与顺序改善叙事，不添写“熬夜”“客户震惊”“突然顿悟”等无记录情节。读者假设场景保持假设语气。

### 示例：有记录的审稿过程

素材：一份经历稿的审稿记录指出，两个案例重复，开场信息过多，过渡句刻意；记录保留了修改建议，没有证据表明全部建议已采纳。

可用开头：
> 我把一份个人经历稿交给模拟顾问做终审。记录里的建议落得很具体：两个故事重复，开头信息太多，过渡句像在报告章节切换。它们指向了接下来的修改方向：让读者更容易看见经历中的判断。

不能升级为“改完后阅读量翻倍”或“所有读者都被打动”；审稿建议和实际改稿结果分别表述。

## 二、从已有判断中提炼金句

金句是一句可记住、可解释的判断，仍须由附近的例子、事实或推理支撑。

1. 找出作者最想保留的判断，列少量候选，每句标出对应的原文或依据。
2. 用明确的主语、动作、对象和必要条件压缩表达；可使用贴合内容的类比，避免套用对立句式。
3. 对照原文检查范围、因果与确定程度。原文只支持“本次”时保留“本次”；作者建议不改成普遍规律。
4. 将最有用的短句放在案例之后、关键判断处或结尾。按信息价值取舍，通常保留少量即可；短文可以不增加，每节无需固定一句。
5. 删除与正文主线无关、脱离原句就无法解释，或反复表达同一意思的候选。

不为追求记忆点编造名人名言、统计数字或效果，不把当前作者原创候选归给顾问人物。流畅性不能替代论据。

### 示例：保留适用范围

原意：本例列出了验收要求，但还没有运行。
候选：**写下验收要求，是定义期望；记录运行结果，才知道发生了什么。**
依据：教学案例中区分了预期行为与实际结果。它不承诺需求清楚就能零返工。

原意：作者写经验时，愿意解释选择背后的理由。
候选：**把选择的理由写下来，经验才更容易被理解和复用。**
依据：作者的经验表达主张；不作为已经测量的复用收益。

## 三、接上去 AI 味与事实核对

推荐顺序：核对观点与证据 → 选择开头素材 → 提炼观点短句 → 按作者样本润色语言 → 再核对事实、范围与语气。
若使用 humanizer 清理套话，保留承担信息作用的场景与短句，继续删除机械反转、空泛格言和重复总结。
标题阶段再检查故事是否兑现标题承诺，故事开头不能延迟核心信息太久。

## 四、完成检查

- 开头对应一件可说明来源的事、一个有来源案例，或明确的假设场景；没有故事材料时直接说明问题。
- 读者能从开头知道为什么需要本文，能顺畅进入正文。
- 保留的每句金句能指向原意或依据，未扩大因果、适用范围或确定程度。
- 没有虚构作者经历、感受、对白、数据和顾问引语。
- 原有关键步骤、作者声音与事实边界保留；删去过密的加粗与重复短句。

交付润色稿，并简要列出“开头用了什么素材”“保留哪些观点短句及位置”“仍缺什么材料”。没有新增短句或没有改故事开头时说明理由。
