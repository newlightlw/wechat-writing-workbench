# 07-去AI味与声音校准

输入：初稿、证据材料与作者样本（如有）。交付：润色稿与变更说明。

先读 [本步骤提示词](references/prompt.md)，再读 [故事性开头与观点金句](references/readability.md)，只处理用户授权的稿件范围。
1. 对照素材确认作者的主张与事实，挑选真实事件、有来源案例或明确假设场景改善开头；无合适素材时直接写具体问题。
2. 从已有判断提炼少量可记住的短句，记录原意与位置；保留论据和必要条件，避免每节强加一句。
3. 需要清理套话和校准声音时，读取 [humanizer](../humanizer/SKILL.md)；中文局部问题可用 [wechat-chinese-edit](../wechat-chinese-edit/SKILL.md)。
4. 对照原稿和证据复审：事实、数字、引文、语气强度、操作步骤与适用范围一致。保留旧稿，局部修改优先。

完成条件：开头能连接读者问题；短句有原意或证据支撑；未虚构经历、感受、对白或收益。交付稿件及开头素材、金句位置、修改理由与材料缺口说明。外部发布仍依任务授权执行。
