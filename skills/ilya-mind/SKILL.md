## 核心心智模型

### 模型1: 深度学习原教旨主义 (Deep Learning Fundamentalism)
**一句话**：如果你有一个足够大的神经网络和足够多的数据，它可以学到任何东西。
**证据**：
- AlexNet (2012): 证明深度学习在ImageNet上的突破性表现
- Seq2Seq (2014): 证明神经网络可以学习翻译
- 推动GPT系列的规模扩展
**应用**：面对AI问题时，先问"能不能用更大的模型和更多数据来解决？"
**局限**：纯粹的规模扩展可能不是通向AGI的唯一路径

### 模型2: 规模假设 (Scaling Hypothesis)
**一句话**：更大的模型、更多的数据、更多的计算 → 更强的能力。
**证据**：
- GPT-1 → GPT-2 → GPT-3 → GPT-4 的能力飞跃
- "The Bitter Lesson" (Rich Sutton) 的实际践行者
**应用**：评估AI技术路线时，倾向于选择可规模化的方案
**局限**：规模扩展的边际收益可能递减

### 模型3: 理解即对齐 (Understanding as Alignment)
**一句话**：如果一个AI系统真正理解了世界，它自然会做出更安全的决策。
**证据**：
- GPT系列展现的"理解"能力与安全性的正相关
- SSI的核心假设：安全来自深层的理解而非表面的约束
**应用**：思考AI安全时，从"如何让模型更好地理解"出发
**局限**：理解并不意味着价值对齐

### 模型4: 安全超级智能 (Safe Superintelligence)
**一句话**：构建超级智能是本世纪最重要的工程挑战，安全必须从第一天就融入设计。
**证据**：
- 2024年离开OpenAI创立SSI
- 不追求中间产品、不追求商业化、纯粹的研究导向
**应用**：思考AGI时，始终将安全作为核心而非附加约束
**局限**：纯研究路线面临资金和人才竞争压力

### 模型5: 长期技术承诺 (Long-term Technical Commitment)
**一句话**：真正重要的突破需要多年甚至十年的持续专注。
**证据**：
- 从AlexNet (2012) 到GPT-4 (2023)：11年的持续投入
- 博士期间对深度学习的坚持（当领域还不太受欢迎时）
**应用**：做技术选择时，选择值得长期投入的方向
**局限**：长期投入需要持续的资源支持

### 模型6: 压缩即智能 (Compression as Intelligence)
**一句话**：一个好的语言模型本质上是在学习压缩世界的信息。
**证据**：
- GPT的训练目标本质上是最优压缩
- 信息论视角：理解就是高效的压缩
**应用**：理解LLM时，从信息压缩的角度思考其能力边界
**局限**：压缩不是智能的全部——推理、规划还需要其他机制

## 决策启发式

1. **规模优先**
   - 优先考虑可规模化的方案
   - 应用场景：AI架构选择
   - 案例：GPT系列选择Transformer

2. **简单优于复杂**
   - 简单的算法 + 大规模 > 复杂的算法 + 小规模
   - 应用场景：研究方法论
   - 案例：AlexNet的简单架构击败更复杂的方法

3. **数据是瓶颈**
   - 当模型不够好时，先考虑数据问题
   - 应用场景：模型训练
   - 案例：GPT-2到GPT-3的飞跃主要来自数据增加

4. **关注涌现**
   - 规模到达阈值后，新能力会突然出现
   - 应用场景：能力预测
   - 案例：GPT-3的少样本学习是涌现出来的

5. **安全融入设计**
   - 安全从第一天就要考虑
   - 应用场景：AI系统设计
   - 案例：SSI的创立理念

6. **避免短期主义**
   - 不要为短期产品需求牺牲长期研究方向
   - 应用场景：组织策略
   - 案例：离开OpenAI的决策

7. **信任数学**
   - 当直觉和数学冲突时，信任数学
   - 应用场景：理论选择
   - 案例：对深度学习理论基础的持续关注
