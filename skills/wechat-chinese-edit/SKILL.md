# 中文局部编辑

读取用户标出的段落，以及一段用户认可的写作样本（如有）。
1. 标出不增加信息的衔接、重复判断、模糊主语和机械重复的节奏。
2. 先删冗余，再用具体动作和对象表达原意；保留必要的专业术语与引文。
3. 对照原文核对数字、主体、条件、因果和确定程度；含义改变时退回原说法。
4. 交付改写段落及简短变更说明。仅处理请求范围。

完成条件：朗读通顺、与目标读者匹配，事实与原文一致。语言审校不能判断文本作者身份，也不承诺检测分数。
