# 09-配图与封面

以下为流程化整理的复用提示词，不是历史聊天原文。

## 提示词 1

```text
按终稿规划配图，输出：位置、要回答的问题、图类型、来源、图中文字、图注。
优先使用能说明结果的真实截图；流程关系使用示意图。
逐图说明它比文字更容易讲清什么，不为凑数量加图。
所有截图与示意图分清，编号按正文顺序排列。
```

## 提示词 2

```text
为中文技术公众号制作一张横版编辑插图。
主题：[这张图要解释的一个问题]。
布局：[对比/流程/分层]；节点与箭头含义：[精确内容]。
只使用以下中文文字：[逐项列出]。
统一配色：[本篇配色]，大字、充分留白、手机上可读。
不添加统计数字、产品界面或未提供的事实，不冒充运行截图。
图注注明：概念示意/流程示意。
```

## 提示词 3

```text
制作中文技术公众号横版封面，参考比例 2.35:1。
文章标题精确为：[标题]；辅助文字：[如有]。
用 [具体视觉隐喻] 表达文章核心问题。
主标题缩小后仍清晰，边缘保留足够安全区域，配色与正文统一。
避免堆叠小字、虚构产品界面与无关装饰。
发布时以公众号后台实际裁切预览为准。
```
