# 思考天团调用提示词

## 自动选顾问
```text
请用思考天团分析这个问题：[问题]。
选择 2—3 个互补框架，说明选择理由，再分别分析。
结合给定材料 [路径] 区分事实、推测与建议，保留分歧，形成可验证的行动计划。
```

## 指定顾问
```text
请用思考天团，以 Polanyi、Paul Graham、张一鸣的模拟视角审阅 [大纲路径]。
重点检查经验能否传达、表达是否清楚、判断是否有事实支撑。
观点是模型推演；引用原话时必须能回查来源。
```

## 文章审稿
```text
对 [稿件路径] 启用文章审稿模式。
按主编、目标读者、技术审校、公众号编辑依次审阅。
每个角色给出最重要的三个问题及具体改法，再汇总修改优先级与保留项。
```

## 分歧辩论
```text
用分歧辩论模式分析 [争议判断]。
先分别形成支持与反对的最强论据，找出分歧的事实依据和适用条件，说明什么新证据会改变判断。
不要为了结论一致抹掉分歧。
```

## 多 Agent 模式（可选）
```text
我明确要求使用独立子 Agent 分别审稿，每位只看相同原稿和证据底稿。
汇总时展示共识、分歧及修改优先级。不要把多个模型的一致意见当成事实证明。
```
