# 纸间 · 公众号排版台

本地 Markdown 转微信公众号富文本工具。文章不会上传到转换服务，原 Markdown 文件不会被修改。远程图片仍由浏览器从原地址读取。

## 使用

1. 双击 `启动排版台.command`，浏览器会打开 `http://127.0.0.1:8796`。保持启动终端运行，按 Ctrl+C 可停止服务。
2. 粘贴 `.md` 文件完整路径，点击「打开文件」。也可导入文件或粘贴 Markdown；导入方式不能取得原始目录，如需读取配图，请另外填写原文件完整路径。
3. 选择配色和字号；默认隐藏正文一级标题，可单独「复制文章标题」。
4. 点击「复制到公众号」，在微信公众号正文编辑区粘贴。
5. 检查图片、表格、代码换行和外链。微信可能过滤剪贴板图片，必要时展开「图片素材」，点击保存后手动上传。此工具不自动发布文章。

支持标题、强调、引用、有序/无序列表、表格、代码块、链接和 PNG/JPG/GIF/WebP 配图。保留受支持的内联文字颜色和粗体，清除脚本、事件处理器及危险样式。使用内联样式提高富文本复制兼容性，微信最终渲染仍以实际粘贴结果为准。

「导出 HTML」会嵌入可读取的本地图片，可离线打开、存档，也可从浏览器复制正文。远程图片保留原 URL，离线可用性取决于缓存。本地图片限定在文章所在目录或其子目录内，每张最多 20MB，文档最多 2MB。Markdown 链接内有空格的路径请使用 `<路径>` 写法。

可选「外链转文末资料」会取消外部链接点击，按出现顺序在文末汇总网址；原文已有参考资料时建议关闭。编辑区改动仅参与当前转换，刷新页面会丢失，请在原 Markdown 编辑器中保存正式内容。

## 命令行

需要 Node.js 20+。首次使用需要联网安装 npm 依赖。

```sh
npm ci
npm start -- --file '/完整路径/文章.md'
```

服务仅监听本机 `127.0.0.1`，默认端口 8796。可用环境变量 `PORT` 修改端口（双击启动脚本使用默认端口）。

## 验证

运行 `npm test` 检查渲染、清理危险 HTML 和格式保留。服务器集成检查见仓库 `scripts/check_formatter.mjs`。公众号实际粘贴与上传仍需在后台检查。
