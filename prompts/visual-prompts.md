# 配图与封面风格模板

以下模板根据真实写作中使用的构图方式重新整理，不包含私人案例或历史文章全文。

## 概念对比图
```text
制作中文技术公众号编辑插图，横版 3:2。
用两张同样大小的工作台对比 [变化前] 与 [变化后]，让读者理解 [一个概念]。
暖白底、深蓝文字、蓝橙强调，留白充足，大字号。
精确文字：[标题]、[左标签]、[右标签]、[底部说明]。
只表达概念关系，不添加统计数字或虚构运行界面，图注注明概念示意。
```

## 信息流图
```text
制作三行左右对照信息图。
左侧：[输入节点]；右侧：[输出节点]；箭头关系：[逐条说明]。
虚线表示 [非直接关系]。所有文字按提供内容原样排版。
统一配色和字体层级，检查箭头指向，图片缩小后仍能阅读。
```

## 教程封面
```text
制作中文公众号教程横版封面，参考比例 2.35:1。
左侧约六成区域放标题：[完整标题]，按照 [分行] 组织层级。
右侧用 [具体视觉隐喻] 表达主题，辅助文字只保留 [标签]。
使用 [本篇配色]，四边保留安全空间，缩略图中标题清晰。
无额外文字和水印，不冒充真实截图。以发布后台实际裁切预览为准。
```
